# PdfCraft engine 0.21.1 on Android

The Android build imports the [upstream 0.21.1 release](https://github.com/storytold/pdfcraft/releases/tag/v0.21.1). The upstream paragraph-editing path handles non-Arabic text and the Android contextual shaping path handles paragraphs that contain Arabic before or after editing. Arabic FreeText appearances use shaped glyphs and carry the logical text. Office import continues to use the on-device converter and Excel export remains available alongside both HTML modes.

The Android release candidate is 0.0.8-rc.1.
