# مانجا TV — Manga TV

تطبيق لقراءة المانجا على **Android TV**، مصمَّم بالكامل للتحكم بالريموت كنترول (أزرار الأسهم + OK + رجوع) بدون ماوس أو كيبورد.

## المصادر المدعومة

| المصدر | ماذا يقرأ |
|---|---|
| **ذاكرة الجهاز** | ملفات `CBZ`/`ZIP` ومجلدات الصور على ذاكرة التلفاز أو فلاشة USB |
| **إضافة مجلد** | أي مجلد عبر منتقي ملفات النظام (إن كان التلفاز يدعمه) |
| **خادم OPDS** | [Komga](https://komga.org) و [Kavita](https://www.kavitareader.com) وأي فهرس OPDS 1.2 — مع بث الصفحات صفحةً صفحة (OPDS-PSE) أو تنزيل CBZ |

طريقة ترتيب المكتبة المحلية: مجلد فيه صور مباشرة = فصل، ملف `cbz` = فصل، وأي مجلد آخر = سلسلة يمكن الدخول إليها.
الترتيب طبيعي (`2` قبل `10`).

> أسهل طريقة للتلفاز: شغّل Komga أو Kavita على الكمبيوتر وضع فيه ملفاتك، ثم أضف الخادم في التطبيق:
> - Komga: `http://IP-الكمبيوتر:25600/opds/v1.2/catalog` مع اسم المستخدم وكلمة المرور
> - Kavita: `http://IP-الكمبيوتر:5000/api/opds/مفتاح-API`

## أزرار الريموت في القارئ

| الزر | الوظيفة |
|---|---|
| ◀ ▶ | الصفحة التالية / السابقة (في وضع المانجا: ◀ = التالية) |
| ▲ ▼ | تمرير الصفحة الطويلة أو شريط الويبتون، ثم الانتقال للصفحة المجاورة |
| OK أو Menu | قائمة القارئ: اتجاه القراءة، الملاءمة، القفز 10 صفحات، الفصل التالي/السابق |
| CH+ / CH− ، ⏮ ⏭ | صفحة سابقة / تالية |
| ⏪ ⏩ | القفز 10 صفحات |
| رجوع | إغلاق القائمة أو الخروج من القارئ |

عند آخر صفحة في الفصل، الضغطة الأولى تُظهر تنبيهاً والضغطة الثانية تفتح الفصل التالي.

أوضاع القراءة: **من اليمين لليسار (مانجا)**، **من اليسار لليمين (كوميكس)**، **عمودي (ويبتون)**، مع **ملاءمة الشاشة** أو **ملاءمة العرض**.
يُحفظ موضع القراءة تلقائياً ويظهر في صف «متابعة القراءة» في الشاشة الرئيسية.
اضغط مطولاً على OK فوق أي مصدر أو عنصر في «متابعة القراءة» لتعديله أو حذفه.

## البناء والتثبيت

```bash
cd apps/manga-tv
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk
adb connect IP-التلفاز
adb install -r app/build/outputs/apk/release/app-release.apk
```

يُبنى الـ APK تلقائياً على GitHub Actions (‏`Manga TV build`) ويمكن تنزيله من قسم Artifacts.
نسخة release موقّعة بمفتاح debug لتسهيل التثبيت المباشر؛ استبدله بمفتاحك قبل أي نشر.

- الحد الأدنى: Android 6.0 (API 23) — الهدف: Android 16 (API 36)
- Kotlin + Jetpack Compose for TV (`androidx.tv:tv-material`) + Coil 3 + OkHttp
- الواجهة بالعربية والإنجليزية حسب لغة التلفاز
